【修订记录】
 v1  初始线框；按单列计算宽度，中文字符导致线框错位（实测 56~59 列）。
 v2  修正为统一 80 列，补齐区域 / 交互 / 数据章节。
 v3  依据评审确认：技术栈 PySide6/Qt、数据源东方财富直连；新增
     分时图 / 盘口五档 / 预警提醒 / 导出·全屏；给出 A/B 两种布局状态。

【v1 校验结论（备查）】
 1. 线框右边框在 56~59 列间跳动，中缝竖线在 14/15 列间跳动。
 2. 根因：中文全角字符占 2 列，v1 按 1 列计算。
 3. 缺失：搜索结果区、完整周期/复权、副图切换、分时/盘口、异常态、数据源定义。
 => v2 起线框全部由脚本按显示宽度生成并断言，杜绝再次错位。

 二、区域与组件
--------------------------------------------------------------------------------
 1. 顶部工具栏
    - 搜索框：代码 / 拼音 / 名称，联想下拉。
    - 周期：分时 / 1m / 5m / 15m / 30m / 60m / 日 / 周 / 月。
    - 复权：不复权 / 前复权 / 后复权（默认前复权）。
    - [五档]：切换右侧盘口面板（布局 A ↔ B）。
    - [预警]：打开预警规则与预警列表。
    - [刷新] / [设置]：手动刷新；数据源、主题、刷新频率配置。
 2. 左侧自选股面板（QDockWidget，可浮动 / 隐藏）
    - 分组树；股票列表（代码 / 名称 / 现价 / 涨跌幅），可排序；
      增删按钮、双击加自选、右键菜单（加入分组 / 移出 / 设预警）。
 3. K 线主图区
    - 蜡烛图叠加均线 MA5/10/20/60，或切换 BOLL。
    - 十字光标浮层、滚轮缩放、拖动平移、画线工具。
 4. 成交量副图：VOL + MAVOL5/10，可折叠、可调高度。
 5. 指标副图：MACD / KDJ / RSI / BOLL 切换，与主图共享时间轴。
 6. 盘口五档（右侧停靠，布局 B）
    - 卖5~卖1 / 买1~买5 的价与量；现价、涨跌、均价、成交量；预警摘要。
 7. 分时图：底部 [分时] 切换，走势线 + 均价线 + 分钟成交量。
 8. 底部工具条：[分时][日K][周K][月K]、指标选择、[导出][全屏]。
 9. 状态栏：数据源 | 更新时间 | 连接状态 | 刷新频率 | 预警数。

--------------------------------------------------------------------------------
 三、交互与状态
--------------------------------------------------------------------------------
 - 加载态：进入显示骨架屏，就绪后填充。
 - 异常态：断网 / 数据源不可用时状态栏转红，提示「离线，展示缓存数据」。
 - 空态：搜索无结果、自选股为空时给出引导文案。
 - 联动：切换左侧标的 → 主图 / 副图 / 盘口 / 状态栏同步刷新。
 - 布局切换：[五档] 在 A/B 间切换，并用 QSettings 记忆。
 - 预警：规则命中 → 托盘通知 + 声音 + 弹窗；列表可启停 / 删除。
 - 导出 / 全屏：导出当前图表为 PNG；F11 或 [全屏] 切换。
 - 快捷键：↑ / ↓ 切换标的，空格刷新，F 全屏。

--------------------------------------------------------------------------------
 四、技术方案（PySide6 / Qt）
--------------------------------------------------------------------------------
 模块划分
   - 表现层  QMainWindow；左 / 右停靠用 QDockWidget；分时与副图用 QTabWidget。
   - 图表层  pyqtgraph（K 线自绘 CandlestickItem），保证缩放与大数据流畅。
   - 数据层  QThreadPool + httpx/requests；信号槽回主线程，UI 不阻塞。
   - 缓存层  SQLite 缓存 K 线（键：code + period + fqt）+ 内存 LRU（快照 / 盘口）。
   - 预警层  本地规则引擎（价格 / 涨跌幅 / 上穿下穿）+ QSystemTrayIcon + QSound。
   - 配置层  QSettings / JSON（分组、布局状态、主题、刷新频率）。
 线程模型：每个订阅标的的轮询任务独立执行，主线程仅渲染，跨线程用 Signal 传数据。

--------------------------------------------------------------------------------
 五、东方财富数据接入
--------------------------------------------------------------------------------
 接口要点（字段号以实测为准，上线前需回归验证）:
   - secid 规则：1.600519（沪市）/ 0.000001（深市）。
   - 实时快照  push2.eastmoney.com/api/qt/stock/get
   - 批量列表  push2.eastmoney.com/api/qt/clist/get
   - K 线      push2his.eastmoney.com/api/qt/stock/kline/get
               参数 klt=101(日)/102(周)/103(月)/1|5|15|30|60(分钟)，fqt=0/1/2 复权
   - 分时      push2his.eastmoney.com/api/qt/stock/trends2/get
   - 五档      stock/get 的盘口字段（卖5~卖1 / 买1~买5 价量）
 工程约束
   - 限频：官方未公开；建议单标的 3~5s、批量合并、失败指数退避，避免并发轰炸。
   - 反爬：按需设置 UA / Referer；解析需容错（字段缺失 / 停牌 / 新股）。
   - 合规：属第三方公开接口，仅供学习研究，注意版权与使用条款，勿商业分发。
   - 缓存：盘后停高频轮询；K 线增量更新，避免全量重拉。

--------------------------------------------------------------------------------
 六、非功能需求
--------------------------------------------------------------------------------
 - 性能：切换标的到出图 < 500ms；千级 K 线缩放流畅。
 - 稳定：网络异常降级到缓存；长时间运行内存稳定。
 - 外观：深浅主题；窗口缩放时各面板按比例伸缩。
 - 兼容：等宽字体下 80 列线框严格对齐（本版本已校验）。
